## Rose / Polar Bar Chart Canvas Generator

An interactive polar area (rose) chart builder supporting up to 12 data points. Each segment's radius is proportional to its value. Built-in datasets include monthly rainfall and compass wind directions. The chart redraws in real time as you edit data or adjust controls.

**Tech:** Vanilla JS, HTML5 Canvas, Tailwind CSS. **How to use:** Edit the data table (label + value), add/remove rows, choose a color scheme (Neon/Ocean/Sunset/Forest/Mono), adjust inner radius, and toggle clockwise direction. Hover a segment to highlight it and see the value. Click "Export SVG" to download a vector version of the chart.
